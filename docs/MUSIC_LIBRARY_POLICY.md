# BORE 2 — soundtrack policy

Normal gameplay on PlayStation, Dreamcast and DS/DSi plays the original song library instead of changing contextual music on each street, venue or clock transition. Title music and manual radio/jukebox controls remain. The original 52 bank entries are retained; the appended 74 arrangements are preserved without changes to the generated audio, bank order, assets or save format.

Hidden music archive: open the jukebox and press Select. The archive lists the appended tracks, which can be played and skipped individually. Triangle (PlayStation/Dreamcast controls) or Area (DS touch button) opts into automatic contextual playback for the current session; switch back with Select then Triangle/Auto to use classic playback. Older banks without appended tracks remain usable. The DS advanced numeric song selector is unchanged except for the automatic mode label.

Android has no soundtrack playback implementation at this revision; this change does not claim Android music parity. The standalone host regression checks all indices in both collections, old banks, no archive entries in default shuffle, and skipping boundaries. Native builds and playback testing are required.
